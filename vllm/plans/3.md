## 数据流

```
Store (release 时):
  /release_kv_cache API
    → Scheduler.release_kv_cache: aging + prepare_store → (gpu_ids, cpu_ids)
    → EngineCore: collective_rpc("offload_release_blocks")
    → GPU Worker: ops.swap_blocks(gpu_cache, cpu_cache, mapping)

Load (新请求时):
  EngineCore.add_request (if sharing_cache_salt)
    → Scheduler.lookup_cpu_cache_for_request → cpu_block_ids
    → BlockPool.get_new_blocks → gpu_blocks
    → collective_rpc("load_release_blocks")
    → GPU Worker: ops.swap_blocks(cpu_cache, gpu_cache, mapping)
    → 注册到 GPU prefix cache → get_computed_blocks 可命中
```

## 使用方式

启动 vLLM 时配置：
```python
# 在 CacheConfig 或命令行中设置
--num-release-cpu-blocks 1000  # 分配 1000 个 CPU blocks
```
